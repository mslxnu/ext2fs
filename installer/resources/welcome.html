This installs ext2fs, a native ext2 file system for macOS, so that ext2 volumes mount like any other disk.

Two things are installed:

  • /Library/Extensions/ext2fs.kext — the file system itself
  • /Library/Filesystems/ext2fs.fs — the bundle that lets the system recognise, mount, format and check ext2 media. It carries newfs_ext2fs and fsck_ext2fs, which are also linked into /usr/local/sbin.

A restart is required. macOS will not load a third-party file system extension until you approve it in System Settings and restart; the last page of this installer explains how.

Please read this before installing. This file system is new and has had limited testing on real volumes. Do not use it for data you have not backed up elsewhere. Volumes using ext3 or ext4 features — a journal, or extents — are mounted read-write with full journal replay on mount.
