ext2fs is installed, but not yet running.

macOS will not load a third-party file system extension until you allow it:

  1. Open System Settings › General › Login Items & Extensions, and allow the extension from com.beako.filesystems. On some versions this appears under Privacy & Security instead, as a message about blocked system software.
  2. Restart your Mac.

After the restart, connecting an ext2 volume mounts it in the Finder. From a Terminal you can also use:

  • newfs_ext2fs — create an ext2 file system
  • fsck_ext2fs — check and repair one

To remove ext2fs, run Uninstall ext2fs.command from the disk image this installer came in.

Remember: keep a backup of anything you care about on an ext2 volume. Volumes with ext3 or ext4 features are mounted read-only by design.
